# panel-cr

`panel.json` reúne indicadores económicos de Costa Rica ordenados a partir de fuentes públicas: Banco Central de Costa Rica (BCCR), SUGEF, INEC, Ministerio de Hacienda (vía el BCCR) y el OIJ (vía el anuario estadístico del INEC).

El archivo se actualiza cada lunes de forma automática desde [econsacs-code/datos-cr](https://github.com/econsacs-code/datos-cr). Cada indicador trae dentro del JSON su fuente, el código de la serie en la fuente y la fecha del dato.

Dirección directa del archivo:

```
https://raw.githubusercontent.com/econsacs-code/panel-cr/main/panel.json
```

Los datos son de las instituciones citadas. Cualquier error de procesamiento es nuestro y se agradece el aviso.
